## Fix round 1 (independent security review)

- HIGH, `route.ts` message-parts schema: replaced `z.record(unknown)` + `.passthrough()` with a strict `z.discriminatedUnion` allowing only `text` (max 4000 chars), `step-start`, and the 5 known `tool-*` part types — closes the `file`-part SSRF/cost vector (AI SDK downloads an arbitrary https URL server-side, ~2 GiB cap, before this route's own body cap applies). New tests: rejects a `file` part, rejects a >4000-char text part.
- MED, `route.ts` `streamText`: added `maxOutputTokens: 1024` and `toolCallConcurrency: 1` — `stepCountIs(6)` bounded steps, not per-step cost or parallel tool-call fan-out. New test asserts both are passed.
