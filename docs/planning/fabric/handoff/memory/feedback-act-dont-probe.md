When the user asks for a plan or artifact, produce it from known facts and justified defaults. Do not run extra inspection commands or re-ask for approval once intent is clear.

**Why:** On 2026-10-28 the user interrupted three times ("just create the plan", "do it") while I was checking package versions and listing Supabase projects for an empty repo.

**How to apply:** Confirm the minimum fact set once, then write. Record assumptions in the output instead of asking. See [[coolskool-project]].
