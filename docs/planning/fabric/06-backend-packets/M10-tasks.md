# M10 — Curriculum coverage + lesson plans

Source: `07-master-plan-v1-v2.md` §3 M10. Migration `0072` (claimed). No new deps. No new permission keys. Owning module `src/modules/academics` (already owns `curriculum_units`, sections, subjects; 05 §3) — new files `curriculum.{schemas,actions,queries,query-defs}.ts`; new tables `lesson_plans`, `curriculum_unit_coverage`. Independent of 0070/0071 (M08/M09). Replaces fixture `CurriculumCoverage` (`src/modules/fabric/types.ts`; fixture fn `curriculumCoverage()` in `src/modules/fabric/demo/learning.ts`) — return type must equal it exactly, no extra fields.

Rulings:
- **Tables (0072).** Both: `id uuid pk`, `institution_id`, `created_at`/`updated_at` + `app.set_updated_at()`.
  - `lesson_plans`: `class_section_id` → class_sections, `subject_id` → subjects, `curriculum_unit_id` → curriculum_units **nullable** (revision lessons), `planned_on date not null`, `title` 1–120, `objectives` 1–2000, `resources` null or ≤ 2000, `created_by uuid not null → profiles`. Index `(class_section_id, subject_id, planned_on)`.
  - `curriculum_unit_coverage`: `class_section_id`, `subject_id` (denormalised from the unit, for grouping and scope), `curriculum_unit_id not null`, `covered_on date not null`, `lesson_plan_id` → lesson_plans `on delete set null` nullable, `notes` null or ≤ 500, `marked_by uuid not null → profiles`. `unique (class_section_id, curriculum_unit_id)` — one fact per unit per section; sections are per academic year, so coverage is per year by construction.
  - DB `check`s mirror the Zod limits exactly.
- **No state machine.** Lesson plans are editable notes; coverage is a fact row (upsert / delete). Neither is in rule 5's immutable list. Deletes allowed and audited.
- **Write scope W** (copy 0026 `assignments_insert` verbatim): `institution_id = any((select app.my_institution_ids(array['owner','principal'])))` or `class_section_id = any((select app.my_class_teacher_section_ids()))` or `(class_section_id, subject_id) in (select t.class_section_id, t.subject_id from app.my_taught_section_subjects() t)`. Admin excluded (no `assignment.manage`), same as assignments.
- **FK binding (lesson 2), in every INSERT/UPDATE `with check`, table-qualified:** section, subject in the row's institution; unit (when set) in the institution **and** `cu.subject_id = row.subject_id` **and** `cu.grade_id = (the section's grade_id)`; `lesson_plan_id` (when set) in the institution **and** same `class_section_id`. `lesson_plans` INSERT also `created_by = (select app.current_user_id())`. Coverage INSERT and UPDATE also `marked_by = (select app.current_user_id())` (re-marking re-stamps).
- **RLS (07 §2.2 + lessons 1, 7: initPlan helpers only, no per-row definer calls):**
  - `lesson_plans` SELECT: `institution_id = any((select app.my_institution_ids(array['owner','principal','admin'])))` or the two teacher branches of W. No guardian/student, accountant, admissions, exam_controller. INSERT/UPDATE/DELETE: W + binding.
  - `curriculum_unit_coverage` SELECT: `institution_id = any((select app.my_institution_ids(app.staff_roles())))` or `class_section_id = any((select app.my_student_section_ids()))` (same shape as `subject_assignments_select`, 0020). INSERT/UPDATE/DELETE: W + binding.
  - Grants mirror 0069. `tests/security/rls-expectations.ts`: `lesson_plans` classes `["C","T"]`, read `owner, principal, admin, teacher`, write `owner, principal, teacher`; `curriculum_unit_coverage` classes `["S+G","T"]`, read all 9 roles, write `owner, principal, teacher` (comments: scope proved in `tests/db/curriculum-rls.test.ts`).
- **Guard triggers (security invoker, BEFORE UPDATE, `code:forbidden`, bypass only `nullif(request.jwt.claims,'')->>'role' = 'service_role'` or `session_user = 'postgres'`, lesson 5):** `app.guard_lesson_plan_identity` — `institution_id`, `class_section_id`, `created_by` never change; `app.guard_coverage_identity` — `institution_id`, `class_section_id`, `curriculum_unit_id` never change. **No security definer functions** in 0072.
- **Permissions (existing keys only):** `curriculum.unit.upsert` → `academics.manage` (owner/principal/admin; RLS 0065 already matches). `curriculum.lessonPlan.upsert`, `curriculum.lessonPlan.delete`, `curriculum.markCovered` → `assignment.manage` (owner/principal/teacher; RLS W narrows the teacher). All queries → `academics.read`.
- **ErrorCode mapping (actions):** RLS `42501` → `forbidden` ("not in your teaching scope"). Guard `code:forbidden` → via `mapSqlError`. `23505` on `curriculum_units (subject_id, grade_id, sequence)` → `conflict`, `fieldErrors.sequence`. Unit/section not visible → `not_found`. Unit subject ≠ `subjectId` or unit grade ≠ section grade → `validation_failed`, `fieldErrors.curriculumUnitId` (action pre-check; RLS is the backstop). `coveredOn` after today in the institution timezone → `validation_failed`, `fieldErrors.coveredOn` (copy `todayInTimezone` from `src/modules/attendance/actions.ts`; non-exported helpers only in `"use server"` files). Update/delete matching 0 rows → `not_found`. Mismatched `lessonPlanId` → RLS `42501` → `forbidden` (no pre-check).
- **Coverage math (`curriculum.coverageBySection`):** rows = `subject_assignments` (section × subject) for sections of the `is_current` academic year (or exactly `classSectionId` when given; `subjectId` filters). `subject` = `subjects.name`; `section_label` = `${grades.code}-${class_sections.name}` (timetable convention); `planned_units` = count of `curriculum_units` for (section grade, subject); `completed_units` = count of coverage rows for (section, subject); `on_track` = `completed_units >= floor(planned_units × elapsed)`, `elapsed` = clamp((today − year.starts_on) / (year.ends_on − year.starts_on), 0, 1), today institution-local. Sorted grade `sort_key`, section name, subject name. Fixed query count (no N+1). **Guardian/student → `forbidden`**: `academic_years` SELECT is staff-only (0002), so pacing cannot be computed for them; they use `curriculum.sectionUnits` (debt row, T7).
- **Honesty badges:** none — real data, no AI, no channel.
- **Audit:** every action, ids/booleans only (no titles, no notes).

Routing (owner: Sonnet + Haiku only): T2, T7 Haiku; T1, T3, T4, T5, T6 Sonnet. Parallel: T1 ‖ T2 → T3 ‖ T4 ‖ T5 ‖ T7 → T6 (T5 and T7 need only T1).

Every new action: `all-actions.ts` import + C-03 fixture in `tests/security/escalation.test.ts`. Every new query: `query-defs` + `all-queries.ts` line + smoke sample in `tests/db/api-query-route.test.ts`. Single-file db runs: `pnpm test:db tests/db/x.test.ts` (no `--`).
