No new deps. Module key **`ptm`** (category Communication, default **off**). New owning module `src/modules/ptm` (owns `ptm_events`, `ptm_event_sections`, `ptm_slots`, `ptm_bookings`, `surveys`, `survey_audiences`, `survey_respondents`, `survey_responses`). Replaces fixtures: none (no PTM/survey fixture exists; the marketplace "surveys" blurbs in `src/modules/fabric/demo/marketplace.ts` stay V3). **Requires MOD merged** (`src/lib/modules/catalog.ts`, `module` required on every definition, `app.module_catalog`/`app.module_enabled` from 0084, `createTestInstitution` and the demo seed store `allModulesOn()`). Builds on M06 (audience shape and role list of `announcement_audiences`) and M13 (seed PTM date 2026-11-21 in `academic_calendar_events`; no FK). Backend + HTTP only; pages/nav are Workstream D.

Rulings:
- **Module (MOD).** One key `ptm` covers both features: `MODULES.ptm = { label: "PTM booking & surveys", category: "Communication", description: "Parent-teacher meeting slot booking and short parent surveys with aggregate results.", default: false }`, placed after `sms`. No `requires`. Every action/query below declares `module: "ptm"`. No job types, so no `JOB_MODULES` row. Definers are not module-checked (MOD: not a security boundary). 0099 inserts `ptm` into `app.module_catalog` (`default_enabled = false`) via `insert into app.module_catalog (key, default_enabled) values ('ptm', false) on conflict (key) do update set default_enabled = excluded.default_enabled`. `app.module_enabled` (MOD, 0084) is defined once and is never redefined here. T1 and T2 commit together; the drift test is red between them. Exactly one "module disabled → forbidden" test (T9).
- **Permissions** (append at each role's tail; other milestones edit the same file). `ptm.manage` = owner, principal, admin. `ptm.slot.manage` = owner, principal, admin, teacher (teacher: own slots, RLS). `ptm.book` = guardian only. `survey.manage` = owner, principal, admin. `survey.respond` = all roles except student (8). Students get nothing (DPDP Act 2023: children's data needs verifiable parental consent).
- **PTM tables.** All have `institution_id`, `created_at`/`updated_at` + `app.set_updated_at()`, RLS on, every user-supplied FK bound to the same institution in `with check` (lesson 2), initPlan helpers only (lesson 7). Constraint names are fixed.
  - `ptm_events`: title 1–120; event_date date; day_starts_at, day_ends_at time (ends > starts); slot_minutes smallint in (5,10,15,20,30); check slot count `extract(epoch from (day_ends_at - day_starts_at)) / 60 / slot_minutes` between 1 and 60; booking_closes_at timestamptz not null; status draft|published default draft; published_at, published_by → profiles; created_by → profiles.
  - `ptm_event_sections`: PK (event_id, class_section_id); event_id → ptm_events on delete cascade; class_section_id → class_sections.
  - `ptm_slots`: event_id → ptm_events on delete cascade; staff_id → staff; seq smallint ≥ 0; created_by → profiles; `ptm_slots_teacher_seq_key` unique (event_id, staff_id, seq) = no teacher overlap by construction; `ptm_slots_id_event_staff_key` unique (id, event_id, staff_id) as composite-FK target. Slot k runs `day_starts_at + k*slot_minutes` for `slot_minutes`; times are derived, never stored. No UPDATE.
  - `ptm_bookings`: event_id, staff_id, slot_id with FK (slot_id, event_id, staff_id) → ptm_slots (id, event_id, staff_id) on delete cascade (a booking can never disagree with its slot); student_id → students; booked_by → profiles; status booked|cancelled default booked; cancelled_at, cancelled_by → profiles; check `(status = 'cancelled') = (cancelled_at is not null)`. Partial uniques: `ptm_bookings_slot_key` (slot_id) where status = 'booked' (no double booking); `ptm_bookings_child_teacher_key` (event_id, staff_id, student_id) where status = 'booked' (one slot per child per teacher). Indexes (student_id), (staff_id, event_id). Cancel keeps the row; re-booking works because the uniques are partial.
- **Survey tables.**
  - `surveys`: title 1–120; description ≤ 1000 null; is_anonymous bool not null default true; questions jsonb not null; status draft|open|closed default draft; closes_at timestamptz not null; opened_at; closed_at; created_by → profiles. Question shape: array of 1–10 objects `{type: "single"|"multi"|"text", prompt 1–200 chars, options?: 2–6 distinct strings 1–80}`; options required for single/multi, absent for text.
  - `survey_audiences`: mirror `announcement_audiences` (0068) exactly (type school|role|grade|section, the same exactly-one-target check) except `role <> 'student'` (23514).
  - `survey_respondents`: PK (survey_id, user_id) = respond once; user_id → profiles.
  - `survey_responses`: survey_id; respondent_user_id → profiles **null unless the survey is not anonymous**; answers jsonb. Answer i aligns with question i: single → integer option index; multi → 1–n distinct indexes; text → string 0–500 chars ("" = skipped).
- **Recipients** (`app.is_survey_recipient(p_survey_id, p_user_id)`): an active membership in the survey's institution, role ≠ student, and any audience matching — `school` = every such member; `role` = that role; `grade`/`section` = guardians linked (guardian_students) to a student with an `active` enrolment in that grade's sections / that section. Parent surveys, so students of a section are not recipients.
- **RLS (07 §2.2, lesson 1).**
  - ptm_events, ptm_event_sections, ptm_slots: SELECT 7 staff roles (`app.my_institution_ids(app.staff_roles())`). Guardians/students never read them directly; they use `ptm_slots_for_student`.
  - ptm_events INSERT owner/principal/admin with status draft, published_* null, created_by = current user; UPDATE owner/principal/admin (guard decides what may change); DELETE owner/principal/admin while draft (action rollback only, no delete action). ptm_event_sections INSERT owner/principal/admin while the event is draft, section bound; no UPDATE/DELETE (cascade only).
  - ptm_slots INSERT/DELETE: owner/principal/admin for any staff (`app.staff_in_institution`), or a teacher with `staff_id = any((select app.my_staff_ids()))` and an event section in `(select app.my_taught_section_ids())`. Event bound.
  - ptm_bookings SELECT: owner/principal/admin all; teacher `staff_id = any((select app.my_staff_ids()))`; guardian/student `student_id = any((select app.my_student_ids()))`. No INSERT/UPDATE/DELETE policy: writes only through the definers.
  - surveys, survey_audiences: SELECT/INSERT/UPDATE owner/principal/admin only (like announcements); INSERT status draft; DELETE while draft (rollback only); audiences INSERT only while the parent is draft, grade/section bound. Recipients use `my_open_surveys`.
  - survey_respondents: SELECT own rows (`user_id = (select app.current_user_id())`). survey_responses: SELECT owner/principal/admin **and** `respondent_user_id is not null` (non-anonymous rows only). No write policies on either.
- **Helpers and definers** (lesson 4: `search_path=''`, qualified names, no dynamic SQL; `public.*` wrapper → `app.*` like `publish_announcement`; wrappers granted to `authenticated` only; internal `app.*` revoked from everyone). New initPlan helper `app.my_staff_ids()` returns setof uuid (caller's active memberships' staff ids; grants like `app.my_student_ids`). Internal `app.section_teacher_ids(p_class_section_id)` = class teacher ∪ `subject_assignments.teacher_id` (same definition as `app.my_taught_section_ids`).
  - `public.ptm_slots_for_student(p_student_id uuid, p_event_id uuid default null)` returns table(event_id, event_title, event_date, booking_closes_at, staff_id, teacher_name, subjects text[], is_class_teacher bool, slot_id, seq, starts_at time, ends_at time, state text, booking_id uuid): caller must be a guardian of the student (`app.guardian_student_ids(<student's institution>)`) else `code:forbidden`; published events with `event_date >= current_date` (IST) whose sections include the student's active section; slots of `app.section_teacher_ids(section)` only; state `mine` (booked for this student; booking_id set) | `taken` (booked by anyone else; booking_id null) | `open`. Ordered by event_date, teacher_name, seq.
  - `public.book_ptm_slot(p_slot_id, p_student_id) returns uuid`: slot/event missing or event draft → `code:not_found`; not the child's guardian → `code:forbidden`; `now() >= booking_closes_at` → `code:invalid_state` "Booking is closed."; child's active section not in the event, or slot teacher not in `section_teacher_ids` → `code:validation_failed`; insert; `unique_violation` caught and re-raised by constraint name as `code:conflict` ("This slot is already booked." / "This child already has a slot with this teacher."); audit `ptm.booking.created` (ids only).
  - `public.cancel_ptm_booking(p_booking_id)`: not found / not the child's guardian → `code:not_found`; status ≠ booked → `code:invalid_state`; `now() >= booking_closes_at` → `code:invalid_state`; sets cancelled + cancelled_at/by; audit `ptm.booking.cancelled`. Only the child's guardians cancel (either parent).
  - `public.my_open_surveys(p_institution_id) returns table(id, title, description, is_anonymous, closes_at, questions jsonb, responded bool)`: open, `now() < closes_at`, caller is a recipient.
  - `public.submit_survey_response(p_survey_id, p_answers jsonb) returns void`: not a recipient → `code:not_found` (no existence leak); not open or past closes_at → `code:invalid_state`; answers shape per rulings → `code:validation_failed`; insert respondent (PK violation → `code:conflict` "You have already responded.") then response. Anonymous: respondent_user_id null and the response's created_at/updated_at = `date_trunc('day', now())` (no per-second timing to correlate). **No audit row** (would record who responded).
  - `public.survey_results(p_survey_id) returns jsonb`: caller owner/principal/admin of the survey's institution else `code:forbidden`. `{surveyId, isAnonymous, responseCount, suppressed, questions: [{index, type, prompt, options?: [{label, count}], texts?: string[]}], responses?: [{respondentName, answers}]}`. Anonymous and responseCount < 3 → `suppressed: true`, `questions: []`. Texts: non-empty, `order by` text (never submission order), max 200. `responses` only for non-anonymous surveys, ordered by name.
- **Guards** (lesson 3: direct PostgREST writes obey the action rules; lesson 5 bypass not needed — the seed inserts final states directly and RLS, not the guards, forces draft on insert).
  - `app.guard_ptm_events_update` (BEFORE UPDATE): only draft→published allowed, needs ≥ 1 section and `booking_closes_at > now()`; stamps published_at/by; every other column change and every other transition → `code:invalid_state`.
  - `app.guard_ptm_slots_write` (BEFORE INSERT OR DELETE): insert with seq ≥ the event's slot count → `code:validation_failed`; delete while a `booked` booking exists → `code:conflict` "Slot has a booking." (cancelled bookings cascade).
  - `app.guard_surveys_write` (BEFORE INSERT OR UPDATE): insert validates the question shape (`code:validation_failed`); update may change only status/opened_at/closed_at; draft→open needs ≥ 1 audience and `closes_at > now()` (stamps opened_at); open→closed stamps closed_at; anything else `code:invalid_state`.
- **ErrorCode mapping (actions).** `code:*` from SQL passes through `mapSqlError`. `42501` → `forbidden`. `23503` → `not_found`. `23514` → `validation_failed`. `23505` on `ptm_slots_teacher_seq_key` cannot surface (slots insert with `ignoreDuplicates`). Update that hits 0 rows → `not_found`. Module off → `forbidden` (MOD gate).
- **Audit.** ids, status, dates and counts only; never titles, question text, answers or names (lesson 10).
- **Honesty.** X08 sends no messages (no SimulatedBadge). The feature is `limited`: no reminders or notifications; parents learn of a PTM/survey via an Announcement or the portal. Workstream D shows `<LimitedBadge>` "No reminders sent — tell parents via Announcements" on the PTM and survey pages. 03-feature-matrix row = limited (T11).
- **India specifics.** Times are school-local IST (`Asia/Kolkata`); `bookingClosesAt` must be before `${eventDate}T${dayStartsAt}:00+05:30` (Zod; shortcut comment: IST-only, upgrade when a non-IST tenant exists). Saturday PTMs are typical, any date allowed. Two parents of one child share bookings (unique per child, either may cancel); siblings book separately. Text limits count characters, so Hindi/regional text works. Anonymous by default; results suppressed below 3 responses; no student respondents (DPDP).
- **Skipped (smallest version).** Notifications/reminders; admin or teacher cancelling or booking on a parent's behalf; teacher-created surveys; event edit/cancel after publish; survey edit/delete; per-slot location; guardian overlap check across teachers; calendar FK (admin adds the PTM to the calendar via `calendar.event.upsert`); waitlists; CSV export of results; AI summaries of text answers; UI.
