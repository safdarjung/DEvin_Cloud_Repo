Rulings:
- **Module keys (owner, MOD).** Every new action/query declares `module`: question bank → `question_bank`; `exam.paper.schedule`, `exams.schedule`, `exams.scheduleConflicts`, `exams.reportCardHtml` → `exams`. M11 adds no nav items (no UI). If MOD's `ModuleKey` union lacks `question_bank`, T1 adds it.
- **Permission.** New key `question.manage` = owner, principal, exam_controller, teacher (s). One key covers read and write (same roles). No admin (no `exam.manage`), no admissions/accountant/guardian/student. Schedule and report card reuse keys: `exam.paper.schedule` + `exams.scheduleConflicts` → `exam.manage`; `exams.schedule` + `exams.reportCardHtml` → `exam.result.read` (RLS scopes).
- **`question_bank`** (0073): id, institution_id, subject_id, grade_id (not null), curriculum_unit_id (null), type `mcq|true_false|short_answer|long_answer`, difficulty `easy|medium|hard`, body 1–4000, options jsonb (CASE check: mcq → `jsonb_typeof = 'array'` and length 2–6; else null), answer 1–4000, marks numeric(5,2) > 0 ≤ 100 default 1, is_active default true, created_by uuid not null → profiles, created_at/updated_at + `app.set_updated_at`. Index `(institution_id, grade_id, subject_id) where is_active`. No DELETE policy: archive = `is_active = false`.
- **RLS `question_bank`** (class C, staff-only like 0023, initPlan helpers, lesson 7). SELECT: owner/principal/exam_controller via `institution_id = any((select app.my_institution_ids(array['owner','principal','exam_controller'])))`; teacher where `(question_bank.grade_id, question_bank.subject_id) in (select cs.grade_id, t.subject_id from app.my_taught_section_subjects() t join public.class_sections cs on cs.id = t.class_section_id)`. INSERT: same scope + `created_by = (select app.current_user_id())` + subject, grade and unit bound to the institution, unit also to the same subject_id + grade_id (lesson 2, table-qualified). UPDATE: owner/principal/exam_controller any row; teacher only `created_by = (select app.current_user_id())` rows in scope; same `with check` binding. Column grant (0037 precedent): `revoke update on public.question_bank from anon, authenticated; grant update (subject_id, grade_id, curriculum_unit_id, type, difficulty, body, options, answer, marks, is_active) … to authenticated` → institution_id/created_by immutable. Admin, admissions, accountant, guardian, student: no policy. `rls-expectations.ts`: `question_bank: { classes: ["C"], read/write: owner, principal, exam_controller, teacher }`.
- **`exam_papers` schedule columns** (0073): `scheduled_at timestamptz`, `duration_minutes int` check 15–300, `room_id uuid → rooms`; checks `(scheduled_at is null) = (duration_minutes is null)` and `room_id is null or scheduled_at is not null`; partial index `(room_id, scheduled_at) where room_id is not null`. Drop + recreate `exam_papers_insert`/`exam_papers_update`: same role set (`app.exam_write_roles()`, initPlan form), same exam/section/subject binding, plus `room_id` bound to the institution. SELECT unchanged (staff only). Guardians/students get no date sheet in M11 (follow-up).
- **Schedule is not a constraint.** `exam.paper.schedule` never rejects overlaps; `exams.scheduleConflicts` reports them. `held_on` stays the canonical date: the action sets `held_on` = institution-local date of `scheduledAt` (tz = `settings.locale.timezone`, fallback `Asia/Kolkata`, same source as `timetable/queries.ts`). `scheduledAt: null` clears time, duration and room, and keeps `held_on`. Exam `published` → `invalid_state`. Direct PostgREST writers (exam_write_roles only) can desync `held_on`; display-only, accepted.
- **Conflict kinds** (papers of one exam): `section_double_booked` (two papers of one section overlap); `room_timetable_clash` (the paper's room has a slot in the latest published timetable on that local weekday whose period overlaps). Half-open intervals (back-to-back = no conflict). Sunday or no room → no timetable clash. Each pair reported once. Skipped: room-vs-room double booking (halls seat several sections; needs capacity), cross-exam overlaps.
- **`AssessmentPlanItem` mapping** (`exams.schedule`): one row per paper with `held_on` not null. `id` = paper id; `title` = exam name; `subject` = subject name; `section_label` = `<grade code>-<section name>` (as `getExamWithPapers`); `date` = `held_on`; `kind`: `unit_test` → `unit_test`, `half_yearly|annual` → `term_exam` (`quiz`/`practical` never emitted: no source); `status`: exam `published` → `published`, `marks_entry|verification` → `marked`, `draft` with `scheduled_at` → `scheduled`, `draft` without → `planned`. Row type `ExamScheduleRow extends AssessmentPlanItem` + `exam_id`, `class_section_id`, `scheduled_at`, `duration_minutes`, `room: { id, name } | null`.
- **Report card HTML.** `GET /api/v1/query/exams.reportCardHtml?format=html&institution=<slug>&input={"examId":…,"studentId":…}`. Query returns `{ html } | null`, built from `getCurrentResult` + `getResultRemark` (RLS: guardian/student own, teacher taught). Never result history. Renderer escapes every interpolated string (`& < > " '`), inline print CSS only, no scripts, no external assets. `toHtmlResponse`: error → JSON envelope unchanged; `null` → 404 `not_found`; `{ html }` → 200 `text/html; charset=utf-8` + `cache-control: private, no-store`, `x-content-type-options: nosniff`, `content-security-policy: default-src 'none'; style-src 'unsafe-inline'; frame-ancestors 'none'`, `referrer-policy: no-referrer`; anything else → 422 `validation_failed`. English only.
- **ErrorCode mapping** by PostgREST `error.code` (`mapSqlError` only maps `code:` messages; raw codes become `internal`): `42501` → `forbidden` ("outside your teaching scope"); `23514`/`23503`/`22P02` → `validation_failed`; update touching 0 rows → `not_found`; paper not in `examId` → `not_found`; room not visible → `validation_failed` with `fieldErrors.papers: ["<index>: room not found"]`; exam published → `invalid_state`. Audit ids/counts only, never question text.
- **Honesty.** No simulated channel in M11. UI pass labels the print view "Print / Save as PDF (browser)" and never claims a PDF or board-format marksheet (F-EXM-09 → `limited`). No AI question generation in M11.
- **Question rules (Zod, T3):** mcq ⇔ options (2–6, each 1–500, unique); mcq answer ∈ options; true_false answer ∈ {`true`, `false`}.
