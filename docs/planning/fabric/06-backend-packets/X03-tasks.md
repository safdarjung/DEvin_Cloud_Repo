Rulings:

Exactly one explicit "module disabled → forbidden" test (T9). RPCs are not module-checked (MOD: not a security boundary).
- **`app.module_catalog` insert.** 0086 inserts `library` (`default_enabled = false`) via `insert into app.module_catalog (key, default_enabled) values ('library', false) on conflict (key) do update set default_enabled = excluded.default_enabled`. `app.module_enabled` (MOD, 0084) is defined once and is never redefined here. The drift test (`tests/db/module-enabled-sql.test.ts`) is red between T1 and T2 — expected; T2 follows T1 directly.
- **Settings** (`institutions.settings.library`, optional, snake_case like the rest; validated by `InstitutionSettingsSchema`, written through the existing `core.institution.updateSettings` — no new settings action): `loan_days` int 1–90 (default 14), `fine_per_day` rupees 0–100 `multipleOf(0.01)` (default 1; 0 = no fines), `max_loans_student` int 1–10 (default 2), `max_loans_staff` int 1–20 (default 5). Not added to `DEFAULT_INSTITUTION_SETTINGS`; missing block or key = default. SQL reads `coalesce((settings->'library'->>'<key>')::<type>, <default>)`; TS reads via `librarySettings(settings)` (T4). The two default sets must match (T3 and T7 tests pin them).
- **Tables** (all: `institution_id` → institutions, `created_at`/`updated_at` + `app.set_updated_at()`, RLS on; constraint names fixed so actions map `23505` by name):
  - `library_books`: title text 1–200 (Unicode — Hindi/regional titles allowed), author text 1–120, isbn text null check `^([0-9]{9}[0-9X]|[0-9]{13})$` (stored normalised: no hyphens/spaces, upper-case X; no checksum). Unique index `library_books_isbn_key` (institution_id, isbn) where isbn is not null. No delete.
  - `library_copies`: book_id → library_books not null; accession_no text 1–30 check `^[A-Z0-9/-]+$` (school accession register number, stored upper-case); status `active|withdrawn` default `active`. Unique `library_copies_accession_key` (institution_id, accession_no); index (book_id). No delete (withdraw instead). "On loan" is never stored: it is an open loan.
  - `library_loans`: copy_id → library_copies not null; student_id → students null; staff_id → staff null; check `library_loans_one_borrower` `num_nonnulls(student_id, staff_id) = 1`; issued_on date, due_on date (≥ issued_on); renew_count smallint 0–2 default 0; returned_on date null (≥ issued_on); fine_amount numeric(12,2) ≥ 0 default 0; fine_waived boolean default false; fine_invoice_line_id → invoice_lines null; issued_by, returned_by → profiles null. Partial unique `library_loans_open_copy_key` (copy_id) where returned_on is null (backstop against double issue). Indexes: (institution_id, due_on) where returned_on is null; (student_id) where student_id is not null; (staff_id) where staff_id is not null. Written only by the RPCs below (no write policies, lesson 3).
- **RLS (07 §2.2, lessons 1/2/7).** Books, copies: SELECT `institution_id = any((select app.member_institutions()))` (every active member; titles are not sensitive, guardians need them for their child's loan); INSERT/UPDATE `app.has_role(institution_id, array['owner','principal','admin'])`, copies' `book_id` bound to the same institution in `with check` (table-qualified subquery). Loans: SELECT `institution_id = any((select app.my_institution_ids(array['owner','principal','admin'])))` or `student_id = any((select app.my_student_ids()))` or `staff_id = any((select app.my_staff_ids()))` — teachers and office staff see only their own loans, never students'. No INSERT/UPDATE/DELETE policy on loans.
- **Guard** `app.guard_library_catalog` (security invoker, BEFORE UPDATE on books and copies): `institution_id` and copies' `book_id` immutable → `code:invalid_state`; copy `status` → `withdrawn` while an open loan exists → `code:conflict` detail `copy is on loan`. Bypass only `request.jwt.claims->>'role' = 'service_role'` (with `nullif`) or `session_user = 'postgres'` (lesson 5).
- **RPCs** (definers: `app.*` body + thin `public.*` wrapper of the same signature granted to `authenticated` only; `app.*` revoked from public/anon/authenticated/service_role; `search_path = ''`, qualified names, institution derived from the copy/loan row, never a caller argument; lesson 4). Caller check on the row's institution: holds owner/principal/admin → proceed; active member with another role → `code:forbidden`; not a member → `code:not_found`. "Today" = `(now() at time zone coalesce(settings->'locale'->>'timezone','Asia/Kolkata'))::date`.
  - `public.issue_library_loan(p_copy_id uuid, p_student_id uuid default null, p_staff_id uuid default null) returns jsonb {loan_id, due_on}`. Order: copy `for update` (missing → `not_found`) → caller check → exactly one borrower else `validation_failed` → borrower row in the copy's institution (else `not_found`) with `status = 'active'` (else `invalid_state`) → copy `withdrawn` → `invalid_state` → open loan on the copy → `conflict` (`copy is already on loan`) → `pg_advisory_xact_lock(hashtextextended('library_borrower:' || <borrower id>, 0))` → borrower has an open loan with `due_on < today` → `invalid_state` (`borrower has an overdue book`) → open loans ≥ limit (`max_loans_student` / `max_loans_staff`) → `conflict` (`borrowing limit reached`) → insert (issued_on today, due_on today + loan_days, issued_by caller) → audit `library.loan.issued` {loan_id, copy_id, borrower_kind, due_on}.
  - `public.renew_library_loan(p_loan_id uuid) returns jsonb {loan_id, due_on}`: loan `for update` → caller check → returned → `invalid_state` → `due_on < today` → `invalid_state` (`overdue — return it first`) → renew_count = 2 → `invalid_state` (`renewal limit reached`) → due_on = today + loan_days, renew_count + 1 → audit `library.loan.renewed` {loan_id, due_on, renew_count}.
  - `public.return_library_loan(p_loan_id uuid, p_waive_fine boolean default false) returns jsonb {loan_id, returned_on, days_late, fine_amount, fine_waived, invoice_line_id}`: loan `for update` → caller check → already returned → `invalid_state` → days_late = greatest(0, today − due_on) (calendar days) → fine = round(days_late × fine_per_day, 2) for a student borrower, 0 for staff (staff are fine-exempt; `p_waive_fine` ignored) → if fine > 0 and not waived: target invoice = the student's non-cancelled invoice in the loan's institution whose term has the latest `starts_on ≤ today`; none → `code:invalid_state` detail `no fee invoice to add the fine to` (nothing written; librarian waives or accountant generates the invoice first); else `app.add_invoice_charge(invoice, 'library_fine', 'Library fine: ' || left(title, 120) || ' (' || days_late || ' days late)', fine)` → set returned_on, returned_by, fine_amount (the computed fine, also when waived), fine_waived, fine_invoice_line_id → audit `library.loan.returned` {loan_id, days_late, fine_amount, fine_waived, invoice_id}.
- **Finance charge (finance-owned, T3).** `app.add_invoice_charge(p_invoice_id uuid, p_head text, p_description text, p_amount numeric) returns uuid` (the new `invoice_lines.id`): invoice `for update` (same lock as `record_payment`; missing → `not_found`) → `cancelled` → `code:invalid_state` → head `^[a-z_]{1,40}$`, description 1–200, 0 < amount ≤ 100000 with ≤ 2 decimals, else `code:validation_failed` → insert `invoice_lines` (concession 0) → invoice `subtotal += amount`, `total += amount`, status `paid` → `part_paid` (others unchanged) → ledger Dr `fees_receivable` / Cr `fee_income` for amount, `invoice_id` set, entry_date = today in institution tz, memo `<head> invoice <invoice_no>` → audit `finance.invoice.charge_added` {invoice_id, line_id, head, amount}. No `public.*` wrapper: execute revoked from public/anon/authenticated/service_role (callers are definers owned by postgres). If 0074 or later added an invoice guard trigger, follow its GUC. No direct ledger or invoice write anywhere in library code. Note for the controller: X04 (0087) also charges invoices — it may reuse this function.
- **Permissions** (`permissions.ts` + 07 §2.2): `library.manage` = owner, principal, admin (catalogue, issue/renew/return, waive); `library.read` = all 9 roles (own loans; RLS scopes). 07 rows: `library.manage (catalogue, issue/renew/return, waive fines)` ✓ ✓ ✓ · · · · · ·; `library.read (RLS: managers all loans; other staff own; guardian own children; student own)` ✓ ✓ ✓ s s s s s s.
- **ErrorCode mapping (actions).** SQL `code:*` passes through `mapSqlError`. `23505` by name: `library_books_isbn_key` → `conflict` fieldErrors.isbn; `library_copies_accession_key` → `conflict` fieldErrors.accessionNos; `library_loans_open_copy_key` → `conflict` "This copy is already on loan.". `42501` → `forbidden`; `23503` → `not_found`; `23514` → `validation_failed`; 0-row update or unknown accession in `ctx.institution` → `not_found`; module off → `forbidden` (MOD). Never `internal` for these.
- **Audit.** Ids, dates, kinds, counts and amounts only — never titles, borrower names or ISBNs in audit, errors or logs (lesson 10). Actions do not re-audit what the RPCs audit.
- **Honesty.** Nothing simulated: no channel, no badge. The later UI states "fines count calendar days, holidays included" (debt row).
- **India specifics.** Rupees as numeric(12,2), integer-paise arithmetic in TS (lesson 8); default timezone Asia/Kolkata; accession-register numbers as the copy identity (librarian types or scans them — a USB barcode scanner is a keyboard); ISBN-10/13 entered with hyphens (978-81-…, 978-93-…) normalised; Devanagari titles accepted; the fine is collected at the fee counter on the term invoice (it prints on the next receipt), no separate fine receipt.
