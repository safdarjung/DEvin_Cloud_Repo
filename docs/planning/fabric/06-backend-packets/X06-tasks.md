Rulings:
- **Slot.** A slot = `(exam_id, slot_start)` where `slot_start` equals an `exam_papers.scheduled_at` of that exam. Students to seat = `students.status = 'active'` with an `enrolments.status = 'active'` row in a `class_section_id` that has a paper of that exam at exactly `slot_start`. Each student once per slot (two papers of one section at the same start — electives — still one seat). Cross-exam slots and staggered starts sharing rooms: skipped.
- **Tables (0088).** `exam_seating_plans`: id, institution_id → institutions, exam_id → exams, slot_start timestamptz not null, version_no int not null check ≥ 1, exam_name text not null check 1–200 (snapshot of `exams.name`: guardians cannot read unpublished exams), rooms jsonb not null check `jsonb_typeof = 'array'` (`[{room_id, seats}]` as resolved, in fill order), section_ids uuid[] not null (sorted), seat_count int not null check ≥ 0, superseded_by uuid → exam_seating_plans(id) `deferrable initially deferred` (0009 `results` pattern), generated_by uuid → profiles (null = seed/service role), created_at/updated_at + `app.set_updated_at`. Unique `(exam_id, slot_start, version_no)`; partial unique `(exam_id, slot_start) where superseded_by is null` (one current). `exam_seats`: id, institution_id → institutions, plan_id → exam_seating_plans, student_id → students, class_section_id → class_sections, room_id → rooms, seat_no int not null check 1–500, created_at/updated_at + trigger. Unique `(plan_id, student_id)`, `(plan_id, room_id, seat_no)`; index `(student_id)`.
- **Writes only through the definer.** No INSERT/UPDATE/DELETE policy. Grants (0045 pattern): `select` to authenticated; `select, insert, update, delete` to service_role; nothing to anon. History is immutable by grant (no guard trigger). Regenerate = new version; the previous gets `superseded_by`; seats are never edited.
- **RLS (initPlan helpers, lesson 7).** Plans SELECT: owner/principal/admin/exam_controller every version (`institution_id = any((select app.my_institution_ids(array['owner','principal','admin','exam_controller'])))`); guardian/student current headers only (`superseded_by is null and institution_id = any((select app.my_institution_ids(array['guardian','student'])))` — a header holds no student data). Seats SELECT: same staff set, all rows; guardian/student `student_id = any((select app.my_student_ids())) and plan_id in (select p.id from public.exam_seating_plans p where p.superseded_by is null)`. The plans policy never references seats (no `42P17` recursion). Teacher, admissions, accountant: no policy (invigilator access skipped; the exam cell prints charts). `rls-expectations.ts`: `exam_seating_plans { classes: ["C"], read: owner, principal, admin, exam_controller, student, guardian, write: [] }`; `exam_seats { classes: ["C", "S+G"], same read, write: [] }`.
- **Generator** `public.generate_seating_plan(p_institution_id uuid, p_exam_id uuid, p_slot_start timestamptz, p_rooms jsonb) returns public.exam_seating_plans` → `app.generate_seating_plan` (definer, `search_path = ''`, qualified names, no dynamic SQL; lesson 4). Checks in this order: no uid and no `service_role` claim (`nullif(current_setting('request.jwt.claims', true), '')::jsonb->>'role'`, lesson 5) → `code:unauthenticated`; exam not in `p_institution_id` → `code:not_found`; caller not in `app.exam_write_roles()` there (skipped for the `service_role` claim only) → `code:forbidden`; exam `published` → `code:invalid_state`; `now() >= p_slot_start` → `code:invalid_state` ("slot already started"); no paper of the exam at `p_slot_start` → `code:not_found`; `p_rooms` not an array of 1–50 `{room_id, seats?}`, duplicate room, room not in the institution, `seats` < 1 or > `rooms.capacity` → `code:validation_failed`; zero students → `code:invalid_state`; students > total seats → `code:conflict` (detail `need <n> seats, have <m>`). Missing `seats` = room capacity. Then: select the current plan `for update`; new id; set the old row's `superseded_by`; insert the plan (version_no = max + 1, exam_name, resolved rooms, sorted section_ids, seat_count, generated_by = `app.current_user_id()`); insert seats in one `insert … select`; catch `unique_violation` → `code:conflict` ("seating plan changed concurrently; retry"); `app.audit` `exam.seating.generated` `{plan_id, exam_id, slot_start, version_no, seat_count}` (ids/counts only). `revoke` the `app.*` function from public, anon, authenticated; wrapper `execute` to authenticated and service_role only. Not module-checked (MOD: not a security boundary).
- **Interleaving (deterministic, in SQL).** Sections of the slot ordered by grade `sort_key`, then section name. `k` = the section's rank by name within its grade. `r` = the student's rank within the section by `roll_no` nulls last, then `admission_no`. Seating order = `(r, k, grade sort_key)` → per rank 6A, 7A, 8A, 6B, 7B, 8B, … Consecutive seat numbers (bench mates) come from different sections while ≥ 2 sections remain, and from different grades while ≥ 2 grades remain at that position. Rooms fill in `p_rooms` order: student n goes to the room whose cumulative seat range holds n; `seat_no` = n − seats of earlier rooms. Same inputs + same enrolments → same seats.
- **Regenerate** only while `now() < slot_start` and the exam is not `published`; any number of versions. Rescheduling a paper (M11) never touches plans: `examSeating.slots` flags `stale` and the exam cell regenerates.
- **Permissions.** New `exam.seating.read` = owner, principal, admin, exam_controller ✓; student, guardian s (own seat, RLS). Generation reuses `exam.manage` (owner, principal, exam_controller = `app.exam_write_roles()`). 07 §2.2 row after `exam.recheck.review / decide`: `exam.seating.read (s = own seat; generate uses exam.manage)` — own ✓ · pri ✓ · adm ✓ · exc ✓ · stu s · grd s.
- **Module.** Every new action/query sets `module: "exam_seating"`. Catalog entry `exam_seating: { label: "Exam seating & admit cards", category: "Exams", description: "Seat students across exam rooms and print room charts and admit cards.", default: false, requires: ["exams"] }`. SQL mirror: 0088 inserts `exam_seating` into `app.module_catalog` (`default_enabled = false`) via `insert into app.module_catalog (key, default_enabled) values ('exam_seating', false) on conflict (key) do update set default_enabled = excluded.default_enabled`. `app.module_enabled` (MOD, 0084) is defined once and is never redefined here; its `requires` AND-chain already enforces `exams`. T1 and T2 land in one commit (the drift test is red between them).
- **Queries** (all `exam.seating.read`, module `exam_seating`). `examSeating.slots` {examId} → `SlotRow[]`; `examSeating.chart` {planId} → `SeatingChart | null`; `examSeating.studentSeats` {studentId} → `StudentSeatRow[]` (current plans, `slot_start > now() − 24 h`, order slot_start, limit 100; RLS: guardian/student own, staff any); `examSeating.chartHtml` {planId} → `{ html } | null`; `examSeating.admitCardsHtml` {examId, classSectionId, studentId?} → `{ html } | null` (null when no paper or no student is visible — guardian/student get 404 because `exam_papers` is staff-only). HTML through M11's `?format=html` (`toHtmlResponse`; its CSP `default-src 'none'` blocks images, so no photo or logo).
- **Stale.** `SlotRow.plan.stale` = the current plan's sorted `section_ids` ≠ the slot's sorted section ids, OR `seat_count` ≠ today's active student count of those sections.
- **Display.** Section label `<grade code>-<section name>` (M11). Times in the institution tz (`institutionTimeZone`, fallback `Asia/Kolkata`) via `localParts`; end = start + `duration_minutes`. Student name = `first_name` + `last_name`, trimmed. English only.
- **Seating chart (HTML).** One page per room that has seats, in plan room order: school name, exam name, local date + start time, room name, "Version <n>", table seat no · roll no · student name · admission no · class-section, footer count. A superseded version prints with a "Superseded — do not use" banner.
- **Admit card (HTML).** One A4 page per student: school name, "Admit Card", exam name, student name, admission no, class roll no (or "—"), class-section; table of every paper of the exam for that section with `scheduled_at` set, in time order: date `YYYY-MM-DD (Ddd)`, start–end, subject, room + seat from the current plan of that slot ("To be announced" when there is none); fixed lines "Bring this card to every paper.", "Reach the exam room 15 minutes before the start.", "Mobile phones and smart watches are not allowed."; signature lines "Class Teacher" and "Principal".
- **ErrorCode mapping.** RPC `code:*` messages → `mapSqlError`; Zod → `validation_failed`. Never raw SQL text; audit ids/counts only.
- **Honesty.** Nothing simulated. Print = browser print / Save as PDF; the UI pass labels it so and never claims a PDF (rule 7). Feature-matrix status `limited (API + HTML print; no UI)`.
- **India.** IST default; Mon–Sat exam days (no weekday rule); "Admit Card" wording (UI may add "Hall Ticket"); A4; class roll numbers; several grades share a hall — the interleave is the anti-copying step schools do by hand today.
