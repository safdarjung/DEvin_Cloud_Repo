- **Algorithm `mastery_v1` — `public.compute_mastery(p_institution_id uuid) returns int`.** Security invoker, `search_path = ''`, qualified names; execute revoked from public/anon/authenticated, granted to service_role. Year = the institution's `academic_years` row with `is_current` (none → return 0). Observations:
  - *mark*: current `marks` (`superseded_by is null`, `not is_absent`, `marks_obtained is not null`) of papers with `cardinality(unit_ids) > 0` of exams with `status = 'published'` and `academic_year_id` = year; one observation per (mark, unit in `unit_ids`); `s = least(1, greatest(0, marks_obtained / max_marks))`, `w = 2`, `on = coalesce(held_on, exams.published_at::date)`.
  - *submission*: `assignment_submissions` with `status = 'graded'` whose assignment has `curriculum_unit_id` not null and whose section belongs to the year; `s = least(1, greatest(0, score / max_score))`, `w = 1`, `on = graded_at::date`.
  - subject = the unit's `subject_id` (join `curriculum_units` on the same institution).
  Per (student, unit), only students with an active enrolment in a section of the year (that section is `class_section_id`): `score = round(Σw·s / Σw, 3)`; `confidence = round(least(1, Σw / 4.0), 2)` (one exam = 0.5; one exam + two graded submissions = 1.0; one submission = 0.25); `mark_count`/`submission_count` by source; `evidence` = `jsonb_agg({src: 'mark'|'submission', id, score: round(s, 3), w, on})` ordered `on desc, id`, first 50; `computed_at = now()`. `insert … on conflict (academic_year_id, student_id, curriculum_unit_id) do update` every computed column, then delete that institution+year's rows with `computed_at < now()` (unit unmapped, mark now absent, student withdrawn). Returns rows upserted. Re-run on unchanged data = identical values and ids. Only published exams count (snapshots are student-visible: no draft leakage).
- **Thresholds — one source, `src/modules/mastery/rules.ts`; SQL read functions take them as arguments, never hard-code them.** Gap unit: `confidence >= 0.5 and score < 0.6`. `meanScore` = average score of the student's units with confidence ≥ 0.5 (null if none). Risk: `support` if gapUnits ≥ 3 or meanScore < 0.40; else `watch` if gapUnits ≥ 1 or trend `down` or attendance_pct < 75 (only when attendance has a denominator); else `none`. Trend: the student's current-version `results.percentage` for the year's published exams ordered by `exams.published_at`; fewer than 2 → `flat`; last − previous ≥ 5 → `up`, ≤ −5 → `down`, else `flat`. Flags, in this order: `"1 unit gap"` / `"<n> unit gaps"` (n ≥ 1), `"Low mastery"` (meanScore < 0.40), `"Declining results"` (trend down), `"Attendance below 75%"`, `"Low evidence"` (no unit with confidence ≥ 0.5), `"Intervention active"` (an `active` or `review` plan). `mastery_pct` = `Math.round(score × 100)`; a student's `mastery_pct` = meanScore as pct, 0 when null. Gaps sort: score asc, subject name, unit sequence.
